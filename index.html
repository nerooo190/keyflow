    MIDI-AUSGANG · VST3 / DAW / HARDWARE

    So spielst du mit VST3-Plugins

    VST3-Plugins laufen in einem Host-Programm auf dem PC/Mac (z. B. Reaper, Cakewalk, Ableton, FL Studio oder der kostenlose Plugin-Host Carla). Keyflow schickt die Noten per MIDI dorthin:

    1. Keyflow auf dem PC starten (node server.js) und in Chrome öffnen.
    2. Virtuelles MIDI-Kabel: Windows → loopMIDI, Mac → IAC-Treiber (Audio-MIDI-Setup), Linux → Carla/ALSA.
    3. Im Host eine Spur mit deinem VST3-Plugin anlegen, MIDI-Eingang = das virtuelle Kabel, Aufnahme-/Monitor-Schalter an.
    4. Hier als Ausgang das Kabel wählen, Kanäle zuordnen, „Nur extern hören“ an.

    Am Handy kannst du so auch die eingebauten Klänge deines MIDI-Pianos (z. B. MEP-4000) oder einen Hardware-Synth ansteuern.
